# YellowKitchen

Учебный проект: сайт доставки еды с корзиной, заказами, регистрацией и админ-панелью.

## Возможности

**Для клиента**
- Каталог ресторанов с фильтром по категориям
- Меню ресторана, корзина, оформление заказа (доставка или самовывоз)
- Бесплатная доставка от 29 €
- Регистрация и вход, история заказов со статусами
- Подписка на рассылку, карта с ресторанами

**Для администратора** (`/admin.html`)
- Статистика: заказы, выручка, клиенты, подписчики
- Заказы: фильтр и смена статуса
- Рестораны и блюда: добавление, редактирование, скрытие, удаление
- Список подписчиков

## Технологии

- Frontend: HTML, CSS, JavaScript (без фреймворков)
- Backend: Node.js, Express
- База данных: SQLite (better-sqlite3)
- Авторизация: JWT, пароли хешируются через bcrypt

## Запуск

Нужен установленный [Node.js](https://nodejs.org) (LTS).

```bash
npm install
npm start
```

Сайт откроется на http://localhost:3000, админка на http://localhost:3000/admin.html.

База `yellowkitchen.db` создаётся автоматически при первом запуске вместе с тестовыми ресторанами и блюдами.

### Администратор

При первом запуске создаётся аккаунт `admin@yellowkitchen.com` с паролем `admin123`.
Свои данные можно задать переменными окружения до первого запуска:

```bash
# PowerShell
$env:ADMIN_EMAIL="you@example.com"
$env:ADMIN_PASSWORD="your_password"
$env:JWT_SECRET="long-random-string"
npm start
```

> Пароль по умолчанию подходит только для локальной демонстрации.

## API (кратко)

| Метод | Путь | Описание |
|---|---|---|
| GET | `/api/restaurants?category=` | список ресторанов |
| GET | `/api/restaurants/:id/dishes` | меню ресторана |
| POST | `/api/register`, `/api/login` | регистрация и вход |
| POST | `/api/orders` | создать заказ (цены считает сервер) |
| GET | `/api/orders/my` | заказы пользователя |
| POST | `/api/subscribe` | подписка |
| * | `/api/admin/...` | только для администратора |
